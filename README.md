# 🏦 Banking Management System

A console-based Banking Management System developed in Java using Object-Oriented Programming (OOP) concepts. This project simulates real-world banking operations such as account creation, deposits, withdrawals, balance inquiries, and transaction management.

## 📌 Project Overview

The Banking Management System is designed to demonstrate the practical implementation of core Java and OOP concepts. The project aims to provide a simple and user-friendly banking environment where users can perform common banking operations securely and efficiently.

## ✨ Features

- Create a new bank account
- Deposit money
- Withdraw money
- Check account balance
- View account details
- Transaction validation
- Exception handling for invalid operations
- Menu-driven console interface

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Exception Handling
- Arrays / Collections
- Packages
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
